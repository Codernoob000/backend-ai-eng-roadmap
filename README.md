# 🚀 Backend + AI Engineering Roadmap

Welcome to my personal engineering ledger. This repository tracks my transition from structural data programming to building scalable production-grade backends, data engineering pipelines, and intelligent agentic AI systems.

---

## 📂 Repository Blueprint

### 🛠️ Phase 1: The Core Data Layer (`/mysql`)
* **`Beginner - Parks_and_Rec_Create_db.sql`**: Relational database setup, schema initialization, and data insertion constraints.
* **`2.select tutorial.sql`**: Data projection basics, calculated field math, and working with unique values (`DISTINCT`).
* **`3.where clause.sql`**: Row-level record filtering, pattern matching (`LIKE`), and complex logical evaluation (`AND`/`OR`/`NOT`).
* **`4.Group by and order by.sql`**: Data aggregation metrics (`SUM`, `AVG`, `COUNT`) and multi-layered sorting logic.
* **`5.where Vs having.sql`**: Advanced record filtering logic, isolating the difference between row-level (`WHERE`) and aggregate-level (`HAVING`) conditions.
* **`6.limit and alaising.sql`**: Result set constraints, position offsets, and clean semantic structural renaming (`AS`).
* **`7.Joins.sql`**: Relational data stitching, mastering `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and advanced positional `SELF JOIN` tracks.
* **`8.Unions.sql`**: Vertical row stacking pipelines and distinguishing between `UNION DISTINCT` and `UNION ALL`.
* **`9.String functions.sql`**: Advanced text manipulation, string formatting, chunking (`SUBSTRING`), and position tracking (`LOCATE`).
* **`10.Case statements.sql`**: Implementing conditional logic (`IF-THEN-ELSE`) directly inside data projection blocks.
* **`11.Subqueries.sql`**: Designing nested, dynamic query components within `WHERE`, `SELECT`, and `FROM` execution clauses.
* **`12.Window functions.sql`**: Advanced data partitioning (`OVER`, `PARTITION BY`), rolling cumulative totals, and ranking mechanisms (`ROW_NUMBER`, `RANK`, `DENSE_RANK`).
* **`13.CTE.sql`**: Structuring Common Table Expressions to optimize query readability and decouple complex named subquery blocks.
